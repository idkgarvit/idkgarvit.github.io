Critical Polygon Technology • HackerOne • Pending Triage

Pimlico Bundler API Key — Unrestricted Write Access on 7 Chains

Discovered a hardcoded Pimlico bundler API key in Polygon's staking JS bundle. The key provides unrestricted eth_sendUserOperation access across 7 EVM chains (Polygon, Ethereum, Arbitrum, Optimisim, Base, etc.). Combined with the on-chain smart wallet factory, an attacker can deploy controlled wallets and execute arbitrary UserOps. Proven via AA21 → AA23 error code transition with correct vs. wrong factory addresses.
